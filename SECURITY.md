# Security Policy

## Reporting a vulnerability

Please report security issues to **zjy.akimiya@gmail.com** instead of opening a
public issue. We aim to acknowledge reports within 48 hours and to ship a fix
for confirmed issues within 14 days.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | :white_check_mark: |

## Scope

The Codex Guard GitHub Action and its .github/workflows in this repository.
Regex-based secret scanning is best-effort and not a substitute for a dedicated
secret scanner — see README Limitations.
