# Support for Codex Guard

## Where to ask

- **GitHub Discussions** (once enabled) — questions, sharing setups, roadmap
  voting: <https://github.com/Akimiya-z/codex-guard/discussions>
- **Issues** — a bug in the action/CLI/skill, or a feature request, via the
  issue templates: <https://github.com/Akimiya-z/codex-guard/issues/new/choose>

## Before asking

1. Read the [README](https://github.com/Akimiya-z/codex-guard#readme) — inputs,
   config file, CLI and skill sections cover most questions.
2. Skim [CHANGELOG.md](CHANGELOG.md) — your issue may already be fixed in a
   newer release.
3. Try the local dry-run first: `npx -y codex-guard --git` in your repo.

## Getting help fast

For bug reports, include: the failing check name, the finding text, your
workflow/config snippet (secrets redacted), and the environment (runs-on,
event type, release version).

## Reporting a security issue

See [SECURITY.md](SECURITY.md) — report privately, not in a public issue.
